# Design Documentation

Must contain:
- Page overview: table with route, page component, purpose
- Component tree: a diagram of pages and components showing parameters down and events up
- Data flow: a diagram for ONE user action from click to updated display, example: "add gamenight"
- Responsibility list: one sentence covering the responsibility of each component and service

Diagrams can be created using `Mermaid`, `draw.io` or by hand. Contents count, not tool used.
